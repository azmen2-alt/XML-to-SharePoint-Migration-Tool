# XML to SharePoint Migration Tool

A Python utility for processing XML-based application records and transforming them into a SharePoint-compatible import format.

## Features

- Recursive XML discovery
- XML parsing and field extraction
- Structured dataset generation
- Data cleaning and validation
- CSV export for SharePoint bulk import

## Tech Stack

- Python
- Pandas
- ElementTree

## Workflow

1. Scan folders for XML files
2. Parse XML fields
3. Build consolidated dataset
4. Normalize identifiers
5. Reformat data for SharePoint
6. Export CSV

## Output

- Clean CSV dataset
- SharePoint-ready column structure

## Sample Use Case

Importing legacy XML application records into a modern SharePoint list.
